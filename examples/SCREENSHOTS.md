# 📸 截图说明

本目录用于存放项目截图和演示文件。

## 如何添加截图

### 1. 生成精读笔记截图

1. 运行快速开始脚本生成一份精读笔记
2. 用浏览器打开生成的HTML文件
3. 截图保存到本目录

### 2. 推荐截图内容

- [ ] 精读笔记整体效果（浏览器截图）
- [ ] 核心理论模块（chapter-card部分）
- [ ] 可视化图表（chart、timeline、mindmap等）
- [ ] 金句摘录（blockquote部分）
- [ ] 落地实践指南（行动建议部分）
- [ ] 命令行输出效果（stats、select等命令）

### 3. 截图命名规范

```
screenshot_模块名_序号.png

示例：
screenshot_overview_01.png        # 整体效果
screenshot_chapter_card_02.png    # 章节卡片
screenshot_chart_03.png           # 图表展示
screenshot_quote_04.png           # 金句摘录
screenshot_action_05.png          # 行动建议
screenshot_cli_06.png             # 命令行输出
```

### 4. 截图工具推荐

**Windows**:
- Snipping Tool（系统自带）
- ShareX（免费开源）
- Greenshot（免费）

**macOS**:
- Screenshot（系统自带）
- CleanShot X（付费）
- Shottr（免费）

**Linux**:
- GNOME Screenshot
- Flameshot（推荐）
- Shutter

### 5. 截图优化

- 分辨率：至少1280x720
- 格式：PNG（清晰）或JPG（压缩）
- 大小：单张不超过1MB
- 背景：使用浏览器默认背景

## 注意事项

1. **隐私保护** - 截图前检查是否包含敏感信息
2. **版权意识** - 书籍内容截图注意版权问题
3. **文件大小** - 压缩图片以加快加载速度
4. **更新维护** - 功能更新后及时更新截图
